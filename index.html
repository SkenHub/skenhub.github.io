私たちについて

舞鶴高専でロボット開発に情熱を注ぐ学生エンジニア集団です

高専ロボコン全国大会優勝とものづくり

舞鶴工業高等専門学校 創造技術研究会 (S-ken) は、高専ロボコン全国大会での優勝とものづくりを通じた成長を目標に活動しているロボット開発チームです。

構想設計から3D CADによるモデリング、マシニングセンタや旋盤を用いた部品加工、マイコン回路やセンサー基板の設計、ROS 2やマイコン制御プログラムの実装まで、すべて部員自身の手で手がけています。

失敗を恐れず試作と検証を高速で回す開発スタイルを大切にしており、初心者から経験者まで学年を越えて技術を高め合っています。

活動環境

  • 活動場所

  • 主な出場大会

年間活動スケジュール

高専ロボコンや春ロボコンに合わせた1年間の開発サイクルです

4月 / 5月

ルール発表 / アイデア出し

高専ロボコンの競技ルールが発表されます。全員で競技分析とアイデア出しを行い、試作ロボットの製作と検証に着手します。

6月 / 7月

ロボット改良 / 本番機製作

試作ロボットで得られた課題をもとに設計を見直し、本番用ロボットの機械加工、基板製作、制御実装を進めて改良を重ねます。

8月 / 9月

作戦立案 / 操縦練習

夏休み期間に模擬フィールドでの走行テストを重ね、相手チームや競技展開を想定した作戦立案と操縦練習を徹底します。

10月

地区大会本番 / 制御改良

近畿地区大会へ参戦します。大会直前までプログラムの改良と操縦練習を詰め、全国大会進出を目指して全力で挑みます。

11月

高専祭

舞鶴高専の高専祭にて、大会出場ロボットの実演デモや操縦体験を実施し、一般来場者や地域の方々と交流します。

12月 / 3月

関西春ロボコン / 冬季研究

3月開催の関西春ロボコンに向けた機体開発や、次年度を見据えた新規センサ・機構・回路の技術開発と冬季研究を行います。
